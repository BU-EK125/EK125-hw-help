# EK125 Homework Help Sessions

This is a companion site to the main [EK125 course site](https://BU-EK125.github.io/EK125/intro.html), collecting the notebooks used in optional homework help sessions -- worked walkthroughs of the problem-solving approach for that week's homework.

Each notebook is a runnable Jupyter notebook. Look for the 🚀 rocket icon in the top-right corner of a page (next to the download button); click it, then **Colab**, to open that notebook directly in [Google Colab](https://colab.research.google.com) and experiment with the code yourself.
